How native releases are handled

  • Android: the release workflow tests and verifies signed .apk and .aab artifacts before publishing them.
  • iPhone and iPad: outside the current supported release scope; use the web ERP in Safari.
  • Mac and Windows: native wrappers remain experimental and are not distributed from this page.
